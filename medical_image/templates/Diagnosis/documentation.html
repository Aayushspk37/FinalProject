Overview

X-HViT Documentation

Welcome to the official documentation for X-HViT — Explainable Hybrid Vision Transformer for medical image classification. This guide covers everything from architecture to integration.

ℹ️ Version: X-HViT v1.0 · February 2026 · License: Academic Research Use

What is X-HViT?

X-HViT is a hybrid deep learning model that combines Convolutional Neural Networks (CNN) for local spatial feature extraction with Vision Transformers (ViT) for global context modeling. It is trained on diverse medical imaging datasets covering 7 disease categories with 95%+ accuracy.

Installation

System Requirements

  • 🐍Python 3.8 or higher
  • 🔥PyTorch 2.0+ (with CUDA optional)

Installation Steps

💡 Note: For GPU support, install PyTorch with CUDA: pip install torch==2.5.1+cu121 --index-url https://download.pytorch.org/whl/cu121

Backbone

CNN Backbone

The CNN backbone extracts local spatial features from the input image. It identifies edges, textures, and patterns that are characteristic of specific diseases.

Specifications

  • ✅Pre-trained on ImageNet (transfer learning)
  • ✅Fine-tuned on medical imaging dataset
  • ✅Extracts features at multiple scales
  • ✅Output: Feature maps for Grad-CAM visualization
🔥 Grad-CAM: The CNN backbone enables Grad-CAM heatmaps that highlight the regions most influential in the classification decision.
Transformer

Vision Transformer (ViT)

The Vision Transformer captures global contextual relationships that CNNs often miss. It models long-range dependencies between different regions of the image.

Specifications

  • ✅Patch embedding with 16×16 patches
  • ✅12-layer transformer encoder
  • ✅Multi-head self-attention (12 heads)
  • ✅Output: Global context for disease classification
🎯 Attention Maps: The ViT provides attention maps that show which parts of the image the model focuses on globally.
Fusion

Hybrid Pipeline

The CNN and ViT outputs are fused to create a hybrid representation that captures both local details and global context.

Fusion Process

  1. CNN Features: Extracted from the CNN backbone
  2. ViT Features: Global attention from the transformer
  3. Feature Concatenation: Both features are combined
  4. Classification Head: Final prediction layer
  5. Dual XAI: Both Grad-CAM and attention maps are generated

Explainability

Explainable AI (XAI)

X-HViT provides dual explainability to ensure every prediction is transparent and verifiable.

Grad-CAM Heatmaps

  • ✅Highlights local regions that influenced the prediction
  • ✅Generated from the CNN backbone
  • ✅Overlayed on the original image
  • ✅Color-coded by importance (red = high, blue = low)

Attention Maps

  • ✅Shows global attention patterns from the transformer
  • ✅Generated from the ViT attention layers
  • ✅Side-by-side comparison with Grad-CAM available
  • ✅Downloadable as PNG overlay
💊 Clinical Trust: Dual explainability ensures that clinicians can verify and trust every AI-assisted diagnosis.
Reporting

Auto-generate structured diagnostic reports in PDF format.

Report Contents

  • ✅Patient Information: Case ID, date, modality
  • ✅Diagnosis: Disease classification with confidence score
  • ✅Probability Distribution: Full class probabilities
  • ✅Grad-CAM Heatmap: Visual explanation overlay
  • ✅Attention Map: Transformer attention visualization
  • ✅Model Metadata: Model version, inference timestamp
📥 Download: Reports are available for download as PDF with one click from the web interface or via the API.
FAQ

Frequently Asked Questions

How accurate is X-HViT?

X-HViT achieves 95%+ accuracy across all supported modalities, validated through 5-fold cross-validation. Specific accuracies vary by disease type.

What image formats are supported?

X-HViT supports JPG, PNG, and DICOM formats. Images are automatically resized to 224×224 pixels before processing.

Is X-HViT HIPAA compliant?

X-HViT is designed for research and educational purposes. For clinical deployment, additional compliance measures may be required.

Can I use X-HViT for commercial purposes?

Please contact us for commercial licensing options. X-HViT is currently available for academic research use.
